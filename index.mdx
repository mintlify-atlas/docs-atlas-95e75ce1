Brave Core is the heart of the Brave browser: a set of changes, APIs, and build scripts that customize Chromium into the privacy-first browser used by millions. It incorporates ad blocking, tracker protection, a built-in crypto wallet, a VPN, anonymous rewards, Tor integration, and much more — all open source under MPL-2.0.

## What's Inside Brave Core

Brave Core is not a fork — it lives inside the Chromium source tree at `src/brave` and applies targeted overrides and additions. Key areas include:

<CardGroup cols={3}>
  <Card title="Brave Shields" icon="shield-halved" href="/features/brave-shields">
    Ad blocking, tracker blocking, and fingerprinting protection powered by adblock-rust.
  </Card>
  <Card title="Brave Wallet" icon="wallet" href="/features/brave-wallet">
    Multi-chain crypto wallet supporting ETH, BTC, SOL, ZEC, FIL, and more.
  </Card>
  <Card title="Brave Rewards" icon="gift" href="/features/brave-rewards">
    Privacy-preserving reward system using anonymous VOPRF credentials.
  </Card>
  <Card title="Brave VPN" icon="lock" href="/features/brave-vpn">
    Built-in VPN with Privacy Pass credentials that decouple payment from usage.
  </Card>
  <Card title="AI Chat (Leo)" icon="robot" href="/features/ai-chat">
    Privacy-preserving LLM integration using OHTTP for secure model inference.
  </Card>
  <Card title="Griffin Variations" icon="flask" href="/features/griffin-variations">
    Staged rollouts and A/B experiments via Brave's Finch-compatible service.
  </Card>
</CardGroup>

## Build Brave in Four Steps

<Steps>
  <Step title="Install prerequisites">
    Follow the platform guide for [Linux](https://github.com/brave/brave-browser/wiki/Linux-Development-Environment), [macOS](https://github.com/brave/brave-browser/wiki/macOS-Development-Environment), [Windows](https://github.com/brave/brave-browser/wiki/Windows-Development-Environment), [Android](https://github.com/brave/brave-browser/wiki/Android-Development-Environment), or [iOS](https://github.com/brave/brave-browser/wiki/iOS-Development-Environment).
  </Step>
  <Step title="Clone and initialize">
    ```bash
    git clone git@github.com:brave/brave-core.git path/to/project/src/brave
    cd path/to/project/src/brave
    pnpm run init
    ```
    This fetches the full Chromium source (~10 GB) and all dependencies.
  </Step>
  <Step title="Build">
    ```bash
    pnpm run build          # component build (fastest for development)
    pnpm run build Release  # release build
    ```
  </Step>
  <Step title="Run">
    ```bash
    pnpm start              # launch the component build
    pnpm start Release      # launch the release build
    ```
  </Step>
</Steps>

<Note>
  The initial build can take several hours depending on your hardware. Subsequent incremental builds are much faster.
</Note>
